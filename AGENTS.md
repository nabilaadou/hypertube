# Repository workflow

- Create a branch and open a pull request for new work. Put follow-up changes on the same branch and pull request until it is merged. Link the relevant issue when one exists.
- Keep `main` changes behind pull requests. Never push changes directly to `main`.
- Leave every pull request open for a human to review and approve the code before a human merges it manually.
- Agents and automation must never merge pull requests or enable auto-merge.
- Use descriptive branch names. Omit agent names, tool prefixes, generated-by notices, and agent co-author trailers from branch names, commits, code comments, and pull request titles, descriptions, and comments.
