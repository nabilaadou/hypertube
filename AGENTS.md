# Repository workflow

- Create a branch and open a pull request for every change. Link the relevant issue in the pull request when one exists.
- Keep `@nabilaadou` and `@sultaaaane` listed as repository-wide code owners in `.github/CODEOWNERS`. GitHub requests eligible code owners for review. A code owner other than the pull request author must approve the changes.
- Keep `main` changes behind pull requests. Never push changes directly to `main`.
- Leave every pull request open for a human to review and approve the code before a human merges it manually.
- Agents and automation must never merge pull requests or enable auto-merge.
